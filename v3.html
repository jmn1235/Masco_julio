✨ Asistente IA (Claude)
La clave queda guardada solo en este dispositivo: no se sube a Firebase ni a GitHub. En cada celular o compu donde uses la app la cargás una vez.
¿Cómo consigo la clave?
  1. Entrá a console.anthropic.com con tu cuenta (es distinta de la suscripción de Claude).
  2. En Billing cargá un saldo chico (con US$ 5 alcanza para meses de uso normal).
  3. En API Keys tocá Create Key, ponele de nombre “Mascotera” y copiala.
  4. Pegala acá arriba y tocá Guardar clave.
Cada consulta descuenta unos centavos de dólar de ese saldo. Abajo ves un estimado de lo gastado este mes desde este dispositivo.
